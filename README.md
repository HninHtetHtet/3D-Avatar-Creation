# 3D Avatar Creation

An Interactive Multimedia Systems project that focuses on creating realistic 3D avatars from facial images using Blender, Unreal Engine 5, and MetaHuman.

## Overview

This project demonstrates a workflow for generating personalized 3D avatars from photographs. The process includes facial feature tracing, 3D modeling, avatar generation, and integration with MetaHuman for high-quality character creation.

## Features

- Photo-based avatar creation
- Facial feature extraction
- 3D face modeling
- MetaHuman integration
- Unreal Engine 5 compatibility
- Realistic digital human generation

## Tools & Technologies

- Blender
- KeenTools FaceBuilder
- Unreal Engine 5
- MetaHuman Creator
- Quixel Bridge

## Workflow

1. Install Blender, Unreal Engine 5, and MetaHuman tools
2. Capture facial images
3. Create a 3D face model using Blender
4. Trace and adjust facial features
5. Generate a MetaHuman character
6. Export and use in Unreal Engine 5
